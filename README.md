# 📓 Death Note
> "I'll take a potato chip... AND EAT IT!" — Light Yagami

## 📖 About
**Death Note** is a Japanese psychological thriller manga written by Tsugumi Ohba and illustrated by Takeshi Obata.

## 📚 Plot
Light Yagami discovers a notebook that can kill anyone whose name is written in it. Using it to eliminate criminals, he attracts the attention of L, a genius detective determined to stop him.

## 🧠 Main Themes
- Justice and morality
- Power and corruption
- Intelligence and strategy
- Good versus evil

## 📜 Death Note Rules
1. A person whose name is written in the notebook will die.
2. The writer must have the person's face in mind.
3. If no cause of death is specified, the person dies of a heart attack.
